# AntiTheft Recovery Web

Next.js App Router portal for future authenticated device management and recovery commands. Phase 0 includes the responsive shell and `/api/health`; it intentionally exposes no unauthenticated device or siren controls.

```powershell
npm.cmd install
Copy-Item .env.example .env.local
npm.cmd run dev
```

Use `npm.cmd run lint` and `npm.cmd run build` for baseline checks.
