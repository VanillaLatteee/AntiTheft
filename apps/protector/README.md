# AntiTheft Protector

Flutter application for Android and iOS. Phase 0 includes the application shell, Riverpod root scope, secure-storage dependency, and a truthful unconfigured dashboard state. Permission onboarding begins in Phase 1; siren playback begins in Phase 2.

```powershell
flutter pub get
flutter analyze
flutter test
flutter run
```

iOS compilation and signing require macOS with Xcode.
